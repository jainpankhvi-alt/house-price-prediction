
# House Price Prediction

A beginner Machine Learning project built using Python and Scikit-learn to predict house prices based on property details.

### Features

* Predicts house prices using four inputs.
* Trained with a Linear Regression model.
* Simple Streamlit web application for predictions.

### Tech Stack

* Python
* Pandas
* Scikit-learn
* Joblib
* Streamlit

### Input Features

* Square Feet Area
* Number of Rooms
* Number of Floors
* Distance from Railway Station (km)

### Project Files

* `train_model.py` – Model training script
* `housemodel.pkl` – Trained model
* `main.py` – Streamlit application
